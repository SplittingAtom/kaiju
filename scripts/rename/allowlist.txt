# Checked by `node scripts/rename/guard.mjs` (CI static job, `pnpm verify`). Format and workflow:
# scripts/rename/README.md. Groups are checked top to bottom and the first entry whose match covers
# an occurrence owns it; an entry that owns nothing fails the guard (delete it). Kept groups
# (permanent, then provisional) protect contents AND file paths: their content entries also match
# paths. Rule: anything persisted in an existing install (database rows and constraints, object
# names in the cluster, S3 keys, signed strings, lock keys, audit names, external repositories) is
# kept, or needs an explicit migration owned by a named step; when unsure, provisional + question.
