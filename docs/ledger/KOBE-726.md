imports, `vi.mock` paths and `new URL(..., import.meta.url)` file reads. Counts of `test` and

imports. Rules: name prefix to the existing folder (`memory-*` to `memory/`, `skill-registry-*`
to `skills/registry/`, `skill-eval-*` to `skills/evals/` and so on); a few by subject (listed in

## Decisions

- **Root sources stay; their tests go to a new `core/` folder.** The 13 root sources (`app.ts`,
  `config.ts`, `pg-listen.ts`, `rate-limit.ts`, `operation-limits.ts`, ...) are imported from all
  over `src/`; moving them would touch dozens of files and conflict with every open lane, so it is
  not cheap. Their tests (`app`, `async-util`, `background`, `config`, `log-safety`,
  `security-headers`, `pg-listen` unit + db, `leader-lock` (pg-listen), `rate-limit`,
  `operation-limits`, `setup-limit` (rate limit on setup)) go to `src/core/`.
- **By subject, not prefix:** `app.isolation` to `isolation/`; `route-inventory` (and its
  `__snapshots__/`) and `site-routes` to `routes/`; `run-token`, `runtime-tamper`, `trace-spans`
  to `sandbox-wire/` (they test wire frames); `sandbox-reclaim`, `workspace-rebuild` to
  `sandbox-lifecycle/`; `sealed-keys`, `startup-seeds` to `startup/`; `site-wall-probe` to
  `audit/`; `usage` (catalog prices, usage) to `budgets/`; `team-filter` (the KOBE-16 guard over
  `threads` queries) to `threads/`; `cursor-wire` to `http/`; `legacy-web-search`,
  `dangerous-mode`, `viewed-file-guard` to `policy/`; `remember-scopes`, `scheduled-auto-deny`
  to `approvals/`; `scim`, `site-sso` to `sso/`; `usage` etc. as in the table.
- **No folder named `install`:** `scripts/site-identifiers.mjs` treats paths with an `install`
  segment specially, so no new folder uses that name.
- **`skills/` flat sources stay flat** (see Open questions): the tests there already sit next to
  their sources; grouping the ~50 flat skill sources is a source refactor across many importers,
  out of scope for a pure test move.

## Path-keyed things checked

- Test selection is by glob only: `vitest.config.ts` (`src/**/*.test.ts` minus `*.db.test.ts`),
  `vitest.db.config.ts` (`src/**/*.db.test.ts`), `tsconfig.build.json` (excludes
  `src/**/*.test.ts`), eslint (`**/*.test.ts`, `services/*/src/**/*.ts` typed files), guards in
  `packages/db` and `scripts/check-site-wording.mjs` (test code matched by `.test.` / `testing/`).
  None needed a change.
- CI `db-server` shards use `vitest --shard=i/2`, which sorts files by a SHA-1 of their path and
  splits by count, so moving files reshuffles but keeps 150/149 files per shard.
- Updated for the new paths: `scripts/onto-main.sh` (route-inventory snapshots now in
  `src/routes/__snapshots__/`, test at `src/routes/route-inventory.test.ts`), `docs/development.md`,
  CLAUDE.md and README (one-file example now `src/core/app.test.ts`), comments in
  `openapi/document.test.ts`, `e2e/run/36-approvals.sh`, `packages/db/src/startup-seeds.ts`.
  Older ticket ledgers and gate documents keep the paths of their time.
- Path fixes inside moved files: relative imports, `vi.mock` paths and `new URL(..., import.meta.url)`
  reads (`connector-site-key`, `skill-promotion`, `skill-review`, `team-filter`'s repo root).
